# ASTRA — Living Town Simulator

A walkable, drivable 3D town with traffic, pedestrians, parks, and a full day/night cycle. Built with [Three.js](https://threejs.org/).

## Run locally

```bash
npm install
npm run dev
```

Open the printed local URL. Use **Cinematic** to orbit the skyline, **Walk** to explore on foot, or **Drive** the red car.

## Controls

| Input | Action |
| --- | --- |
| `W A S D` | Walk / steer |
| Mouse | Look (click the town first) |
| `Shift` | Sprint |
| `C` | Cycle camera |
| `H` | Hide UI |
| Day-cycle slider | Speed up sunrise and dusk |

## What’s in the town

- Grid of downtown towers, shops, houses, and parks
- Autonomous cars and buses that stop at lights
- Pedestrians on sidewalks
- Fountain plaza, street lamps, traffic signals
- Day / night lighting with glowing windows after dark
